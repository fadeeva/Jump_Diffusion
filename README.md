## Project 1: GBM vs. Jump Diffusion. Visualization and Analysis
**Key findings:**
1. Jump Diffusion(Merton Model) trajectories have sharp jumps that are absent in GBM.
2. The Jump Diffusion(Merton Model) return distribution has heavy tails (kurtosis of MM vs GBM).
3. As $\lambda$ (jump frequency) increases, the probability of extreme losses (CVaR 95%) increases.
